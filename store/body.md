身内が亡くなったあと、**何を、いつまでにするか**を返すシステムです。

死亡後の手続きを並べたページは無数にあります。ほとんどが同じことを書いていて、困るのは2点です。**どれが自分に要るのか分からない**ことと、**根拠がどこにも書かれていない**ことです。

このシステムは、そこだけを解いています。

■ 要らないものを消す

手続きは48件ありますが、全部やる人はいません。故人の状況を37項目から選ぶと、当てはまるものだけが残ります。実測で、48件が11〜14件になります。

世帯主だったか。持ち家か。山林はあるか。年金を受け取っていたか。介護サービスを使っていたか。チェックを入れるのがつらい方のために、**文章で書いても読み取ります**（「父が亡くなった。年金受給者。持ち家あり。世帯主だった。国民健康保険。」）。

■ 期限に条文が付いている

期限は改正で動きます。相続登記の3年は2024年4月1日に施行されたもので、それ以前は義務ですらありませんでした。条文を持っていなければ、古い解説をそのまま写すことになります。

各手続きのページに、**根拠の条文そのもの**と、e-Gov法令検索への出典リンクが載ります。

条文まで降りたので、よく見る書き方との食い違いが見つかりました。

- **死亡届の7日は「亡くなった日から」ではありません。** 戸籍法86条1項は「死亡の事実を知つた日から七日以内」。離れて暮らしていて数日後に知ったなら、そこから7日です
- **年金の死亡届は、出さなくてよい場合があります。** マイナンバーが年金に収録されていて、死亡日から7日以内に死亡届が出ていれば不要（厚生年金保険法98条4項ただし書）。要らない窓口へ行かせないために、これは画面に出します
- **世帯主変更届は、残る世帯員が1人だけなら要りません**
- **農地の届出は「遅滞なく」**（農地法3条の3）。10か月は相続税の期限で、別の話です
- **山林を相続したら90日以内**に市町村へ届出（森林法10条の7の2）。相続登記の3年とは別の、もっと短い期限です

■ 市区町村ごとのページ

全国1,912市区町村（政令指定都市20市の区と東京23区を含む）ぶんのページがあります。その市区町村の窓口でできる手続きと、その地域で1年間に何人が亡くなっているか、全国で何番目か、1日あたり何件の死亡届が出ているかが出ます。

政令指定都市は**区役所が窓口**なので、市で1本にまとめず区ごとに分けています。

■ 自分のサーバーに置けます

PHP1ファイルとSQLite1本だけです。データベースサーバーも常駐プロセスもポートも要りません。

**入力された故人の情報は、どこにも送りません。** 外部のAIにもAPIにも出しません。財産・保険・家族構成が入る欄なので、そこは動かしていません。手元にGPUがあれば、文章の読み取りをローカルのLLMに任せる経路も同梱しています（外部通信ゼロ）。

市区町村の役所、議員事務所、士業の事務所が、自分の地域の葬祭費の金額や窓口の課名を足して使う作りです。手続きデータは `data/procedures.json` の1ファイルなので、事務所の方が自分で直せます。

■ 置き方

1. kacnavi.php と kacnavi_data/ を置く
2. その階層の .htaccess に AddHandler php-script .php を書く
3. ブラウザで開く

PHP 8 と PDO SQLite だけで動きます。

■ しないこと

- **相続放棄をすべきかどうか、相続税がかかるかどうかは判断しません。** 弁護士・司法書士・税理士へつなぐ前提です
- **葬祭費の金額は出しません。** 条例と運用で市区町村ごとに違うためです。市区町村の公式サイトの本文は転載していません
- 期限は目安です。受付時間・必要書類は窓口で確かめる前提の作りです

■ データを新しくする

同梱のPythonを動かせば、最新の条文で作り直せます。

```
python3 scripts/fetch_law.py      # e-Gov法令検索から条文を取る（24法令）
python3 scripts/fetch_cities.py   # 市区町村（総務省）
python3 scripts/fetch_stats.py    # 人口・死亡者数（総務省）
python3 scripts/verify_law.py     # 条文の引用34件を検算（落ちたら公開しない）
python3 scripts/build_db.py
python3 scripts/selftest.py       # 画面を実際に叩いて中身を見る（18件）
```

`verify_law.py` は、書いた期限の日数が条文の本文に出てくるかを1件ずつ突き合わせます。**改正で条文が動けば、ここで落ちます。**

■ 出典

- 条文 … デジタル庁「e-Gov法令検索」法令API v2
- 市区町村 … 総務省「全国地方公共団体コード」
- 人口・世帯数・年間死亡者数 … 総務省「住民基本台帳に基づく人口、人口動態及び世帯数」（人口は令和8年1月1日現在、人口動態は令和7年1月～12月）

いずれも政府標準利用規約（第2.0版）。出典を示したうえで商用利用できます。
